# 盘中策略共享内存方案（2026-10-26）

用户已选择共享内存方案。本目录是新增版本，原 `../盘中.py` 和 QMT 中已安装的策略保持原样。

## 目标与边界

- QMT 内置 Python 只调用内置行情接口，通过 Windows 命名匿名内存映射传输结果；不打开磁盘数据文件、不使用 socket、Redis 或 HTTP。
- 外部 Python 加载原 `盘中.py`，用行情适配器替代 ContextInfo；保持计算、Redis 键、去重、钉钉和日志逻辑。
- 桥仅开放行情方法，不开放下单、撤单或任意代码执行接口。
- QMT 端是独立单文件，兼容安装目录中的 Python 3.6；不依赖外部模块搜索路径。
- 本机普通 Python 的测试通过，不代表券商 QMT 环境允许 mmap。实际客户端验证前明确标注未验证。
- 本次不运行实际扫描、不写生产 Redis、不发送钉钉、不停止或重启 QMT。

## 传输协议

同一 Windows 登录会话中的三个 `Local\\` 命名匿名映射：请求 1 MiB、响应 32 MiB、状态 4 KiB。QMT 与外部程序使用同一频道。每个方向单写者；外部入口持有命名互斥量，防止重复启动。

消息为压缩 UTF-8 JSON，不使用 pickle。帧包含版本标识、奇偶写入序号、长度和 CRC32；读取两遍帧头，拒绝半写入、损坏和超限数据。请求有 ID、服务实例 ID 和截止时间，响应必须匹配；过期请求不执行。心跳及服务实例变化用于识别停止和重启。

QMT 回调每秒轮询，在有限时间内处理行情请求。股票名和证券详情批量取得并缓存，避免逐股跨进程等待。DataFrame 转为明确的列、索引和数据结构，外部重建 pandas 对象。
