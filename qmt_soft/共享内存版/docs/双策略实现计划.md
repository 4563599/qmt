# 盘中与 THS 双策略共享内存实现计划

**目标：** 使用已验证的行情桥，在外部 Python 执行两份原脚本，保持计算、Redis 数据、定时任务和提醒行为。

**架构：** 默认盘中启动方式保持兼容，新增 THS 单独运行和双策略运行选项。双策略在同一外部进程中使用独立模块、独立 ContextInfo 适配器和独立工作线程；单个 RPC 客户端用锁串行访问现有共享内存请求槽。每日历史更新保留盘中 09:15、THS 09:25 的原设置，每秒回调仍由原脚本决定交易时段。QMT 继续仅运行现有行情桥，不导入两份原脚本。

**不变项：** 原 `../盘中.py` 与 `../ths筛选.py` 字节不修改。Redis 输入、输出和 Lua；盘中条件、快照、K 线、涨停梯队、钉钉路由与去重；THS 股票池、清洗分组、收盘对齐、增量 K 线及性能 CSV 均调用原函数。传输增加的等待时间不应误判为策略条件或日期改变，实际盘中性能仍需交易时段核实。
